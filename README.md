# Yii2 Bootstrap Multiselect Widget

An easy-to-use Yii2 widget wrapper for [David Stutz's bootstrap-multiselect](https://github.com/davidstutz/bootstrap-multiselect) plugin. 

It automatically detects whether your Yii2 application uses **Bootstrap 4** or **Bootstrap 5** and loads the appropriate plugin version (v1.x for Bootstrap 4, v2.x for Bootstrap 5) via CDN.

## Installation

The preferred way to install this extension is through [composer](https://getcomposer.org/download/).

Either run:

```bash
composer require ianez/yii2-bootstrap-multiselect
